# 📓 Cuaderno Space Apps 2026

Mi cuaderno técnico para el **NASA Space Apps Challenge 2026** (14–15 nov, con EPM en San Vicente Ferrer).

> **El sistema:** el cuaderno físico **piensa** (ideas, esquemas, porqués), este repo **recuerda** (comandos, código, sintaxis). Todo lo técnico va aquí, en imprenta digital 😄

## Cómo uso este repo
1. Estudio el tema del día → apunto las ideas a mano en el cuaderno.
2. Lo técnico (comandos, código, links) lo pongo aquí en su carpeta.
3. Commit + push. Siempre.
4. Antes de empezar el día nuevo: leo la nota de ayer (2 min).
